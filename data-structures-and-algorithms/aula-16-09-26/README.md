# Roteiro: Merge Sort e Quick Sort

Arquivo: [Roteiro_Merge_quick_sort.pdf](Roteiro_Merge_quick_sort.pdf)

Resumo
- Este roteiro apresenta os algoritmos de ordenação Merge Sort e Quick Sort, com explicações conceituais, pseudocódigos, análise de complexidade e exercícios práticos.

Conteúdo principal
- Descrição do funcionamento de Merge Sort (dividir, conquistar, combinar).
- Descrição do funcionamento de Quick Sort (particionamento, escolha de pivô).
- Análise de complexidade: melhor, médio e pior caso; uso de memória.
- Pseudocódigos e exemplos passo a passo.
- Exercícios e propostas de implementação em Python.

Como usar
- Abra o arquivo PDF para ler o roteiro completo.
- Utilize o roteiro para guiar implementações em Python ou outras linguagens.
- Tarefas sugeridas: implementar ambos os algoritmos, medir tempos, comparar com sort nativo.

Pré-requisitos
- Conceitos básicos de algoritmo e recursão.
- Ambiente Python (opcional) para implementar e testar os algoritmos.

Referências e recursos adicionais
- CLRS ou qualquer livro/texto sobre algoritmos para aprofundamento.
